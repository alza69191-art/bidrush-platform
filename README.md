# BidRush

منصة مزاد عكسي مباشر للأعمال الرقمية السريعة.

## نموذج العمل
- العميل ينشر مهمة محددة وميزانية قصوى وموعد تسليم.
- مزاد تنازلي مباشر مدته الافتراضية خمس دقائق، بعروض تُتحقق على الخادم.
- العميل يختار العرض الأنسب، ثم يبدأ التنفيذ والتسليم والتقييم.
- حسابات المستقلين والوسطاء مجانية دون اشتراكات أو رسوم إدراج.
- إيراد المنصة عمولة الإيداع فقط، وتُعرض للعميل قبل الدفع.

## التقنية
Next.js App Router, TypeScript, Tailwind CSS, MySQL-compatible TiDB, server-side authorization, and WebSockets for live auctions.

## التشغيل
انسخ .env.example إلى .env.local ثم أدخل بيانات الاتصال محلياً. لا ترفع الأسرار إلى GitHub ولا ترسل كلمات المرور في المحادثات. شغّل npm install ثم npm run dev.

## حالة المشروع
هذا تأسيس تقني وواجهة أولية. التسجيل الحقيقي والمزايدات الحية والمدفوعات والحجز المالي تحتاج تنفيذ واختبارات إضافية قبل الإطلاق. لا نسمّي أي سجل داخلي Escrow ولا نستقبل أموالاً حقيقية قبل التحقق من مزود الدفع وأهليته ودعمه للحجز والتحرير والاسترداد.
