# BidRush Roadmap

1. Authentication: signup, login, email verification, password reset, secure sessions and RBAC.
2. Profiles: client/freelancer onboarding, skills, portfolio, availability and moderation.
3. Task publishing, categories, search and safe file metadata.
4. Live reverse auction: server clock, transactional bid validation, WebSocket broadcasts and audit trail.
5. Workroom: messaging, delivery, revisions, acceptance and disputes.
6. Deposits: provider sandbox, disclosed deposit fee, signed webhooks, idempotency and refunds.
7. Admin: users, tasks, fee settings, support inbox, audit logs and analytics.
8. Automated tests, security review, accessibility, localization and concurrency/load tests.

Current commit is a foundation and branded UI, not a complete production marketplace. No real payments until provider eligibility and escrow support are verified.
